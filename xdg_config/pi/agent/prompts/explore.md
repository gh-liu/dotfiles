Explore candidate options for: ${@:-the problem or requirement under discussion}

1. Lead with the constraints supported by the code and its contracts.
2. Compare viable options side by side, including the smallest change that meets those constraints. Show how the options differ, where each could fail, and which assumptions remain unverified.
3. If only one option fits, say why instead of inventing a second.

Leave the choice to the user: do not recommend an option, modify files, or implement it.
